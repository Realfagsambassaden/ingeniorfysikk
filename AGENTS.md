# For KI-agenter (Claude, Codex, Copilot m.fl.)

Dette er et fagrepo for fysikkhjelp.no (Realfagsambassaden). Felles regler for alle fag ligger i Plattform-repoet. Les dem før du skriver eller endrer noe:

1. **Notasjon** (går foran alt annet): https://github.com/Realfagsambassaden/Plattform/blob/main/NOTASJON.md
2. **Skriveregler** (oppbygging av sider, oppgaver, tone, merking, kontroll og levering): https://github.com/Realfagsambassaden/Plattform/blob/main/SKRIVEREGLER.md
3. **Agentinstruks**: https://github.com/Realfagsambassaden/Plattform/blob/main/AGENTS.md
4. Emnekartet, som `emne:` og `delemne:` må stemme med: https://github.com/Realfagsambassaden/Plattform/blob/main/emner.yml

Kort: skriv på norsk (bokmål), bruk punktum som desimaltegn, merk eget stoff med `<!-- tillegg: Claude -->`, behold `<!-- fra notatene -->`, og regn ut alle svar på nytt. Skriv aldri rett til `main`, men bruk en gren og en pull request. Se også `BIDRA.md` i dette repoet.
